News Summarizer with Fact Check Notes

NewsLens AI reads a news article, summarizes it, and checks its key claims against live web sources, so you can see what is backed by evidence and what is not.

The problem

There is more news online than anyone can read, and much of it contains claims that are unverified or false. Checking each claim by hand takes time, so it is often skipped and misinformation spreads.

The solution

The app extracts the article, writes a short summary, picks out the factual claims, searches the web for evidence, and gives each claim a verdict with a short note and its sources.

How AI helps

A large language model understands the text, writes the summary, finds the claims worth checking, and judges each claim using only the evidence retrieved for it.

How fact-checking works

  1. The article text is extracted from a URL or pasted directly.
  2. The AI writes a summary and key points.
  3. It extracts the verifiable factual claims and ignores opinions.
  4. For each claim, a web search finds relevant sources.
  5. The sources are split into chunks and turned into vectors, and the most relevant chunks are retrieved. This is Retrieval-Augmented Generation (RAG).
  6. The AI gives a verdict using only that evidence: Supported, Partially Supported, Contradicted, Insufficient Evidence or Unable to Verify.

Limitations

  • AI can still make mistakes in reasoning.
  • Search results might not always return the best or most complete information.
  • Lack of evidence does not prove a claim is false.
  • The tool is an assistant for readers, not a replacement for professional journalism and fact-checking.
